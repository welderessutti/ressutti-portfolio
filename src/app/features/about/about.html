About Welder Ressutti

I am a full-stack software developer specialising in Angular, Java and Spring, with a focus on architecture, performance and user experience.

I design and build modern, robust and scalable end-to-end applications by integrating responsive front ends with reliable back-end services.

From analytical rigour to software engineering

Professional journey

Before moving into software development, I spent 11 years working in biomedicine and managing a clinical laboratory. That environment required analytical thinking, responsibility, attention to processes, leadership and consistent decision-making.

I carried those principles into software development. After completing a degree in Systems Analysis and Development and postgraduate studies in Java Architecture and Development, I specialised in full-stack software development with Angular, Java and Spring. I approach software as a system that should remain understandable, testable and reliable as its requirements evolve.
