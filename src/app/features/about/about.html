About

Full-stack Developer specialising in Angular and Spring for modern, scalable and robust web applications.

I design and develop end-to-end web applications, combining responsive Angular interfaces, Spring back-end services and the integration between them. My focus is clear architecture, maintainable code and reliable behaviour as products evolve.

From analytical rigour to software engineering

Professional journey

Before moving into software development, I spent 11 years working in biomedicine and managing a clinical laboratory. That environment required analytical thinking, responsibility, attention to processes, leadership and consistent decision-making.

I carried those principles into software development. After completing a degree in Systems Analysis and Development and postgraduate studies in Java Architecture and Development, I specialised in full-stack development with Angular and Spring. I approach software as a system that should remain understandable, testable and reliable as its requirements evolve.
